FLUXO DE UMA REQUISIÇÃO:

HTTP Request (Gin)
    ↓
pkg/handler/varconfig/handler.go
  ├─ Valida params (orgId, benchmark_id, id)
  ├─ Faz bind do JSON body
  ├─ Chama ValidateCreateRequest()
  ├─ Monta VarConfig e chama service
  └─ Propaga context.Context
    ↓
internal/service/domain/varconfig/service.go
  ├─ Valida regras de negócio
  ├─ Registra métricas de latência
  ├─ Loga operações (Debug/Info/Error)
  ├─ Define timestamps
  └─ Chama repository com context
    ↓
internal/storage/dynamodb/varconfig/repository.go
  ├─ Constrói PK = "ORG#{orgId}#BENCH#{benchmark_id}"
  ├─ Constrói SK = "VARCONFIG#{id}"
  ├─ Executa operação DynamoDB otimizada
  ├─ Registra métricas de storage
  ├─ Loga operações DynamoDB
  └─ Retorna dados convertidos
    ↓
HTTP Response (JSON)

ROTAS DA API:

Coleção
  GET    /org/{orgId}/compliance/variables/{benchmark_id}
  POST   /org/{orgId}/compliance/variables/{benchmark_id}

Específico
  GET    /org/{orgId}/compliance/variables/{benchmark_id}/{id}
  PUT    /org/{orgId}/compliance/variables/{benchmark_id}/{id}
  PATCH  /org/{orgId}/compliance/variables/{benchmark_id}/{id}
  DELETE /org/{orgId}/compliance/variables/{benchmark_id}/{id}

OPERAÇÕES DYNAMODB OTIMIZADAS:

Create (Save)
  └─ PutItem com PK + SK
  └─ Métrica: storage_varconfig_create_failures_total

Read (FindByID)
  └─ GetItem com PK + SK
  └─ Métrica: storage_varconfig_get_failures_total

List (FindAllByBenchmark)
  └─ Query com PK (ZERO Scan!)
  └─ Métrica: storage_varconfig_list_failures_total

Update
  └─ UpdateItem com PK + SK
  └─ Métrica: storage_varconfig_update_failures_total

Delete
  └─ DeleteItem com PK + SK
  └─ Métrica: storage_varconfig_delete_failures_total
